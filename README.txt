IMPORTANT BEFORE PUBLIC LAUNCH
1. Confirm the app's correct name, features, version and download file.
2. The privacy policy is a TEMPLATE. Replace all placeholders and verify every statement against the actual app's data practices.
3. Test the APK and video on mobile devices.
4. The video is a silent promo. Add licensed music/voiceover if desired.
5. This ZIP does NOT register or purchase a domain. You need to buy a domain from a registrar separately.

PUBLISH FREE WITH GITHUB PAGES
1. Create a GitHub repository (for example: luxy-ai-site).
2. Upload the CONTENTS of this folder (not the ZIP itself) to the repository's root.
3. In GitHub, open Settings → Pages.
4. Choose deployment from the main branch and root folder, then save.
5. GitHub will show the published site address.

CONNECT YOUR OWN DOMAIN
1. Buy a domain from a registrar.
2. In repository Settings → Pages → Custom domain, enter your domain and save.
3. Follow GitHub's current DNS instructions at https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
4. Wait for DNS to propagate, then enable HTTPS in Pages settings.

DIRECT APK LINK AFTER PUBLISHING
Your download page links to ./downloads/luxy-ai.apk. Once the website is live, that will download the included APK from your own domain.

This is a static website; it does not include a server, account system, analytics, or backend API.
